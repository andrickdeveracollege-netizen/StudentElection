# Student Election

A web-based SSLG election system for M. B. Asistio Sr. High School - Unit 1.

**Website:** [studentelection.vercel.app](https://studentelection.vercel.app/)

## Features

- Voter information form and ballot submission.
- Admin dashboard for managing candidates and viewing results.
- Vote records and Excel export.
- Responsive layout for desktop, tablet, and mobile.

Built with ASP.NET Core, HTML, CSS, and JavaScript. Supports PostgreSQL and SQL Server.
